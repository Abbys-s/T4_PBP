# LKP 3A - To-Do List dengan JavaScript Murni

## Isi folder
- `index.html` : struktur halaman aplikasi
- `style.css`  : tampilan aplikasi
- `app.js`     : logika aplikasi dan penyimpanan localStorage

## Cara menjalankan
1. Ekstrak folder `lkp-3a`.
2. Buka folder tersebut.
3. Klik dua kali `index.html` atau buka melalui browser.
4. Ketik tugas pada kolom, lalu tekan tombol Tambah.
5. Coba centang checkbox, hapus tugas, lalu refresh halaman untuk menguji localStorage.

## Fitur
- Menambahkan tugas.
- Menandai tugas selesai/belum selesai.
- Menghapus tugas.
- Menghapus semua tugas yang sudah selesai.
- Menampilkan jumlah tugas dan progres.
- Menyimpan data secara otomatis menggunakan localStorage.

## Catatan
Data disimpan pada browser/perangkat yang digunakan. Jika data browser dihapus atau aplikasi dibuka pada browser/perangkat lain, data lokal tersebut tidak otomatis berpindah.
